# Pose Estimation using YOLOv8

## Overview
This project demonstrates pose estimation using the YOLOv8 model from the Ultralytics library. It processes both images and videos to detect and annotate human poses, saving the results as annotated outputs.

---

## Features
- **Pose Estimation for Images**: Annotate key joints and skeletal structures in static images.
- **Pose Estimation for Videos**: Process video frames and generate annotated videos with human poses highlighted.
- **YOLOv8 Model**: Utilizes the lightweight and efficient YOLOv8 pose-specific model.

---

## Prerequisites
To run this project, ensure you have the following installed:
- **Python 3.8+**
- **Libraries**:
  - `opencv-python`
  - `ultralytics`
  - Other dependencies (`pip install -r requirements.txt`)
